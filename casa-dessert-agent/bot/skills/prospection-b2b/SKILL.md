# Prospection B2B — Casa Dessert

1. Clarifier l’offre pro : parfums, formats, prix, fréquence, minimum de commande.
2. Cibler : restos/cafés **sans dessert maison**, salons de thé, traiteurs, hôtels boutique (IDF ou zone choisie).
3. Rythme : **2 contacts qualifiés / semaine** + relance devis sous 7 jours.
4. Script court : présentation 30 s, échantillon, prochaine livraison test.
5. Suivre : nom, statut (prospect / essai / actif / perdu), prochaine action datée.

Ne pas supposer que l’ancien site ou CRM existe — proposer tableur ou notes `vision_note`.
